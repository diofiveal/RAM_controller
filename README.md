# RAM_controller
# Описание
RAM controller - контроллер для управления синхронной однопортовой памятью. Данный модуль может выступать составной частью более сложных проектов.

Пояснение обозначений:

clk - тактовый сигнал, устройство работает по фронту clk;

rst_n - синхронный сигнал сброса. При rst_n = 0 происходит сброс;

wr - при 1 устройство выбирает режим записи;

rd - при 1 устройство выбирает режим чтения;

data_in - входные данные для записи;

done - сигнал выполнения операции. Если done = 1, то операция выполнена, и модуль готов выполнять следующую операцию;

data_out - выходные данные при чтении

# Features
1) Контроллер для управления синхронной однопортовой памятью;
2) Поддерживаются операции чтения из памяти и записи в память;
3) Дизайн полностью синхронен: все операции выполняются по положительному фронту сигнала clk;
4) Предусмотрена защита от одновременного чтения и записи. В этом случае выполняется операция записи;
5) Модуль имеет параметризированную архитектуру. Имеется возможность настраивать разрядность данных (DATA_SIZE) и глубину памяти (ADDR_SIZE) с помощью parameters;
6) Используется одна и та же шина для чтения и записи;
7) Модуль содержит самопроверяемый testbench

# Getting started
Этот раздел поможет вам быстро настроить окружение и запустить симуляцию проекта в Vivado.

### Шаг 1: Создание проекта

- Запустите Vivado;
- В окне Quick Start Нажмите Create Project. В появившимся окне нажмите Next
- Далее выберете название проекта и директорию. После выбора нажимаем Next
- В появившимся окне выбираем RTL project и жмем Next. 
- В следующих двух окнах жмём Next
- В появившимся окне выбираем плату, на которой будет происходить синтез. Нажимаем Next и Finish

### Шаг 2: Добавление файлов
- В окне Sources выберите Add Sources
- В появившемся окне выбираем Add or create design sources
- Нажимаем Add files и выбираем файлы:
									controller.sv 
									fsm_controller.sv
									ram.sv
- Нажимаем Finish
- В окне Sources выберите Add Source
- В появившемся окне выбираем Add or create simulation sources
- Нажимаем Add files и выбираем файл tb_controller.sv
### Шаг 3: Настройка симуляции

- В окне Sources найдите файл testbench (tb_controller.sv) 
-  Нажмите на него правой кнопкой мыши и выберите Set as Top 
#### Шаг 4: Запуск симуляции

В панели _Flow Navigator_ перейдите в раздел Simulation и нажмите Behaveour Simulation.
